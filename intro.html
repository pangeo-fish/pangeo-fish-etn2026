Fish geolocation with Pangeo-Fish#

Biologging tags (data storage tags, pop-up satellite tags) and acoustic telemetry produce long time series of temperature, pressure and detection events, but no direct position. pangeo-fish is an open source Python package built on the Pangeo ecosystem (Xarray, Dask, HEALPix) that reconstructs the most probable trajectory of a tagged fish by comparing the tag records with an ocean reference model. This hands-on workshop of the ETN Symposium 2026 introduces the Pangeo ecosystem and walks participants through a complete pangeo-fish geolocation workflow, from loading a tag to visualising the estimated track, on the Pangeo@EOSC cloud platform. No installation is needed: everything runs in your web browser.

Time, location and registration#

The workshop takes place on Thursday 15 October 2026, 15:00 - 16:00 CET, as one of the concurrent workshops of the ETN Symposium 2026 (see the symposium schedule).

Venue: B!NGS Copenhagen, Vesterbrogade 149, 1620 København, Denmark.

Please follow the registration to Pangeo@EOSC steps before the workshop: the approval of your enrollment is done manually and may take some time.

Overview#

In this workshop, participants will learn how to 1) navigate the Pangeo ecosystem (Xarray, Dask, HEALPix) for scalable analysis of ocean data and 2) use pangeo-fish to geolocate a tagged fish from its biologging data (temperature, pressure) and acoustic detections, using an ocean reanalysis from the Copernicus Marine Service as reference.

All the training material is developed collaboratively and made available online with a CC-BY-4 licence. To facilitate user on-boarding, the Pangeo@EOSC platform is made available to participants, with a ready-to-use Docker image containing pangeo-fish. However, all the information needed to set up and run the training material on other platforms is provided too.

Learning objectives#

By the end of this workshop, learners will be able to:

  • Understand the Pangeo ecosystem and its role in scalable analysis of oceanographic and biologging data.

  • Open, explore and visualise an ocean model (GLORYS, from the Copernicus Marine Service) with Xarray, scale the computation with Dask and save results as Zarr.

  • Understand what HEALPix is (an equal-area Discrete Global Grid System), why pangeo-fish uses it, and how to convert and plot data on it with xdggs.

  • Run the pangeo-fish geolocation workflow on a biologging tag: compare the tag with a reference model, build emission probabilities, add acoustic detections, optimise and visualise the estimated trajectory.

Prerequisites#

Before starting this workshop, learners should have:

  • Basic knowledge of R or another programming language (no Python experience is required: the notebooks are written for R users);

  • Basic knowledge of biologging / fish tracking data (data storage tags, acoustic telemetry);

  • A Copernicus Marine Service account (free), used by the pangeo-fish notebook to download the reference ocean model.

Set up#

If you are participating in this workshop as part of the ETN Symposium 2026, you will run the notebooks on Pangeo@EOSC. Please register following the instructions given in Registration to Pangeo@EOSC before the workshop. If you wish to continue using the Pangeo@EOSC infrastructure after the workshop, you can keep using the same account.
