# Timeline of the workshop

Thursday 15 October 2026, 15:00 - 16:00 CET, ETN Symposium 2026 (concurrent workshops), B!NGS Copenhagen.

The participants are mostly R users with little or no Python experience. With one hour, the hands-on blocks are short: we run the notebooks together and explain what happens, and you can go through the optional sections and the full notebooks at your own pace afterwards (the book stays online).

| Time   | Activity                                      |
| ------ | --------------------------------------------- |
| 15:00  | 👋 Welcome: introduction and motivation, what is pangeo-fish? (5 minutes) |
| 15:05  | Accessing Pangeo@EOSC: log in, start the pangeo-fish environment with the one-click link, check your Copernicus Marine account. Pangeo in a nutshell while the servers start (10 minutes) |
| 15:15  | Hands-on 1: ocean model data in Python. Open GLORYS with Xarray, select and plot a piece of it, convert it to HEALPix and plot with xdggs (15 minutes) |
| 15:30  | Hands-on 2: fish geolocation with pangeo-fish, from the tag data to the estimated trajectory (20 minutes) |
| 15:50  | Q&A, next steps and the [feedback survey](feedback) (10 minutes) |
| 16:00  | End of the workshop |

Before the workshop (see [Registration to Pangeo@EOSC](users-getting-started)):

- register to EGI Check-in and enroll in the `vo.pangeo.eu` Virtual Organisation (manual approval, do it early),
- create a (free) [Copernicus Marine](https://data.marine.copernicus.eu/register) account,
- if you can, log in to Pangeo@EOSC and start the environment with the one-click link once before 15:00, so that we do not lose time on it during the workshop.
