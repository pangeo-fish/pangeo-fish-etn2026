# Timeline of the workshop

Thursday 15 October 2026, 15:00 - 17:00 CET, ETN Symposium 2026 (concurrent workshops), B!NGS Copenhagen.

The participants are mostly R users with little or no Python experience, so the pace is slow and each hands-on block is followed by a few minutes to catch up and ask questions.

| Time   | Activity                                      |
| ------ | --------------------------------------------- |
| 15:00  | 👋 Welcome: introduction and motivation, what is pangeo-fish? (10 minutes) |
| 15:10  | Accessing Pangeo@EOSC: log in, start the pangeo-fish environment with the one-click link, check your Copernicus Marine account (15 minutes) |
| 15:25  | Catch-up and questions (5 minutes) |
| 15:30  | Hands-on 1: ocean model data in Python. Open GLORYS with Xarray, compute with Dask, save as Zarr, convert to HEALPix and plot with xdggs (25 minutes) |
| 15:55  | Catch-up and questions (5 minutes) |
| 16:00  | ☕️ Break (10 minutes) |
| 16:10  | Hands-on 2: fish geolocation with pangeo-fish, from the tag data to the estimated trajectory (40 minutes) |
| 16:50  | Q&A, feedback and next steps (10 minutes) |
| 17:00  | End of the workshop |

Before the workshop (see [Registration to Pangeo@EOSC](users-getting-started)):

- register to EGI Check-in and enroll in the `vo.pangeo.eu` Virtual Organisation (manual approval, do it early),
- create a (free) [Copernicus Marine](https://data.marine.copernicus.eu/register) account.
